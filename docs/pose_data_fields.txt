POSE DATA FIELDS REFERENCE
==========================
All values computed by core/angle_calculator.py from a keypoints dict.
Keypoints format: name → (x, y, z, visibility)  — x,y in [0,1], y increases downward.
All angles computed from x,y only (z ignored — too noisy).

BACKEND AVAILABILITY KEY
  [BOTH]  — available from MediaPipe and YOLO11
  [MP]    — MediaPipe only (returns 0.0 with YOLO11 due to missing landmarks)
  [SIDE]  — most meaningful from a side-view camera
  [FRONT] — most meaningful from a front-view camera

YOLO11 missing landmarks: left/right_heel, left/right_foot_index, left/right_index (finger)
MediaPipe provides all 33 landmarks. YOLO11 provides 17 COCO keypoints:
  nose, left/right_eye, left/right_ear, left/right_shoulder, left/right_elbow,
  left/right_wrist, left/right_hip, left/right_knee, left/right_ankle

BEND VALUES  (0° = straight, increases as joint bends — USE THESE in all analysis code)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Computed as: bend = 180° − raw_angle

Field                     Landmarks used              Clinical scale
─────────────────────────────────────────────────────────────────────
left_knee_bend_2d   [BOTH] hip → knee → ankle         0°=straight, 45°=quarter squat,
right_knee_bend_2d  [BOTH] hip → knee → ankle         70°=half squat, 90°=parallel squat
                                                       (thigh horizontal = physio target).
                                                       "Full squat" threshold: min 75°.
left_hip_bend_2d    [BOTH] shoulder → hip → knee      0°=upright, 45°=moderate flexion,
right_hip_bend_2d   [BOTH] shoulder → hip → knee      90°=hip at right angle.
                                                       "Full" threshold: min 60°.
left_elbow_bend_2d  [BOTH] shoulder → elbow → wrist   0°=straight arm, 70°=right angle,
right_elbow_bend_2d [BOTH] shoulder → elbow → wrist   120°=hand near shoulder.
                                                       "Full curl" threshold: min 70°.
trunk_lean_2d       [BOTH] hip_mid → shoulder_mid      0°=upright, increases leaning forward.
                                                       IDENTICAL to trunk_lean_angle —
                                                       always use trunk_lean_2d.
                                                       SIDE: forward lean. FRONT: side-bend.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Field                     Landmarks used              Notes
─────────────────────────────────────────────────────────────────────
left_shin_angle     [BOTH] ankle → knee               Shin from vertical. SIDE: forward lean
right_shin_angle    [BOTH] ankle → knee               of shin = knees-over-toes proxy.
                                                       0° = shin vertical. ~20–30° typical squat.

                                                       (~15–25°) than MediaPipe (~30–35°) for

left_thigh_angle    [BOTH] knee → hip                 Thigh from vertical. SIDE: squat depth.
right_thigh_angle   [BOTH] knee → hip                 0° = standing, 45° = quarter squat,

SIGNED VALGUS ANGLE  (frontal-plane knee alignment)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Field                     Landmarks used              Notes
─────────────────────────────────────────────────────────────────────
left_knee_valgus    [BOTH] hip → knee → ankle         0° = collinear (ideal alignment)
right_knee_valgus   [BOTH] hip → knee → ankle         Positive = valgus (knee caving inward)
                                                       Negative = varus (knee bowing outward)
                                                       ±3° = clinically meaningful
                                                       ±5° = clearly visible
                                                       ±10° = severe
                                                       Best used from FRONT-view camera.
                                                       NEVER use abs() — sign is the direction.

SPINE CURVATURE  (signed, normalised silhouette deviation)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Field                     Landmarks used              Notes
─────────────────────────────────────────────────────────────────────
spine_curvature_ratio[SIDE]hip/shoulder + YOLO11-only Signed deviation of the back's
                           segmentation mask          silhouette from a straight
                                                       hip-to-shoulder line, normalised
                                                       by that line's length.
                                                       Positive = back bulges outward
                                                       (excessive rounding).
                                                       Negative = back caves inward
                                                       (excessive arch).
                                                       WARNING: sampled periodically
                                                       (~4x/sec, not every frame) —
                                                       most frames have this field
                                                       == None. None is the NORMAL,
                                                       common value here, not an
                                                       error — always None-check
                                                       before comparing, and never
                                                       assume a numeric default.
                                                       NEVER use abs() — sign is the
                                                       direction, same caveat as
                                                       left/right_knee_valgus above.
                                                       [MP]: always None — YOLO11
                                                       segmentation only, unlike every
                                                       other field in this doc [MP]
                                                       here means "MediaPipe: absent",
                                                       not "0.0 default".

LATERAL SPAN VALUES  (normalised image x-axis distance between bilateral pairs)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
~0 when body is fully sideways to camera; ~0.2–0.4 when facing forward/backward.

Field                     Landmarks used              Notes
─────────────────────────────────────────────────────────────────────
shoulder_lateral_span[BOTH]abs(right_shoulder_x       Profile stance detection.
                            − left_shoulder_x)        < 0.10–0.15 = side-on to camera.
                                                       > 0.15 = facing camera.
                                                       Use in detect_rep to reject
                                                       non-profile frames.
hip_lateral_span    [BOTH] abs(right_hip_x            Same interpretation as shoulder span.
                            − left_hip_x)
knee_lateral_span   [BOTH] abs(left_knee_x
                            − right_knee_x)
ankle_lateral_span  [BOTH] abs(left_ankle_x           In side profile: ~0 = feet side by side;
                            − right_ankle_x)          > 0.20 = one foot significantly in front
                                                       of the other (staggered stance).

RAW KEYPOINTS  (available directly via pose_data["keypoints"])
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Format: pose_data["keypoints"][name] → (x, y, z, visibility)

Available with BOTH MediaPipe and YOLO11:
  nose
  left_shoulder,  right_shoulder
  left_elbow,     right_elbow
  left_wrist,     right_wrist
  left_hip,       right_hip
  left_knee,      right_knee
  left_ankle,     right_ankle

Available with MediaPipe ONLY (absent from YOLO11 keypoints dict entirely):
  left_heel,       right_heel
  left_foot_index, right_foot_index
  left_index,      right_index   (finger tip)
  left_eye,        right_eye     (MediaPipe also provides eye/ear/mouth landmarks
  left_ear,        right_ear      but these are not used in angle_calculator)

YOLO11 keypoints with confidence < 0.3 are excluded from the dict entirely.
MediaPipe always includes all 33 landmarks; low-confidence ones have low visibility scores.
Guard pattern for missing keypoints: visibility == 0.0 is the sentinel (absent).
angle_calculator returns 0.0 for any angle whose required landmarks are absent.
